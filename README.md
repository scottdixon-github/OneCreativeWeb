# Creative Web Inc.

Full-featured web development services website built with React, Vite, TailwindCSS, and Framer Motion.

## Features

- **6 Web Development Services** — Custom Websites, E-Commerce, Web Apps, Mobile/PWA Design, UI/UX Design, SEO & Performance
- **Individual service detail pages** with features, technologies, pricing, and delivery timelines
- **Portfolio showcase** with project cards
- **About page** with company values and team
- **Contact form** with service selection and budget ranges
- **Responsive design** — mobile, tablet, and desktop
- **Smooth animations** powered by Framer Motion
- **Modern dark UI** with gradient accents

## Tech Stack

- React 18
- Vite 5
- TailwindCSS 3
- Framer Motion
- Lucide Icons
- React Router v6

## Getting Started

```bash
npm install
npm run dev
```

The dev server starts on `http://localhost:3000`.

## Build

```bash
npm run build
npm run preview
```
